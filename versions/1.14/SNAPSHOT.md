# Tracer 1.14 source snapshot

This is the editable code snapshot for Tracer 1.14. It intentionally contains no downloaded models, Python environment, generated application, installer, verification media, or user library data.

For development and local launching, it shares the version 1 model/state repository at `C:\projects\TransPro\data`. The legacy folder and `TRANSPRO_DATA` environment name are retained so existing projects, models, analytics, and library records remain connected. Use `Launch Tracer 1.14.vbs` to start this exact code snapshot.

Version 1.14 adds direct-versus-embedded search hit counts, highlighted transcript matches, persistent and collapsible adaptive search results, and a compact navigation rail. It introduces the Projects editing room with tabbed sequences, linked multitrack clips, core timeline edits, markers and zoom, an export queue, Premiere-compatible XML export, portable used-media collection, and offline-media relinking. Small GPU, VRAM, and RAM meters report Tracer usage alongside total system usage. The planned palette overhaul remains deferred.

Do not place minor-version model or analytics copies in this folder. Version 2 will receive a separate major-version shared model repository. Models should be bundled into `dist` and an installer only when an exportable build is explicitly requested.
