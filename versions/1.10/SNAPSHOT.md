# Tracer 1.10 source snapshot

This is the editable code snapshot for Tracer 1.10. It intentionally contains no downloaded models, Python environment, generated application, installer, verification media, or user library data.

For development and local launching, it shares the version 1 model/state repository at `C:\projects\TransPro\data`. The legacy folder and `TRANSPRO_DATA` environment name are retained so the rename does not disconnect existing projects, models, analytics, or library records. Use `Launch Tracer 1.10.vbs` to start this exact code snapshot.

Version 1.10 uses the Tracer product name, removes the Frames search scope, makes Audio and Visual icon-only, changes See All into an overlaid left drawer that does not reflow the media dashboard, and uses saturated Windows-blue, File-Explorer-yellow, and WhatsApp-green selected tiles with black symbols.

The version 2 Story Editor and later offline-AI design notes are preserved in `ROADMAP.md`.

Do not place minor-version model or analytics copies in this folder. Version 2 will receive a separate major-version shared model repository. Models should be bundled into `dist` and an installer only when an exportable build is explicitly requested.
