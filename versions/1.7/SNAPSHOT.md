# TransPro 1.7 source snapshot

This is the editable code snapshot for TransPro 1.7. It intentionally contains no downloaded models, Python environment, generated application, installer, verification media, or user library data.

For development and local launching, it shares the version 1 model/state repository at `C:\projects\TransPro\data`. Use `Launch TransPro 1.7.vbs` to start this exact code snapshot through the shared development environment.

The 1.7 Process interface adds a gear-only side-expanding Advanced panel; a single Capture row with Scene Change; a joined JPEG/PNG selector on Image Quality; a highlighted Save Results area; much smaller opaque output boxes; a restored data-network symbol with an overlapping search lens; and a compact right-aligned Start action.

Do not place minor-version model copies in this folder. Version 2 will receive a separate major-version shared model repository. Models should be bundled into `dist` and an installer only when an exportable build is explicitly requested.
